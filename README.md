# SHOPIX

## AI-Powered Smart Receipt & Shopping Assistant

SHOPIX is a smart web application that helps users organize shopping receipts, track expenses, manage warranties, receive reminder notifications, and view spending analytics.

### Features
- Upload Receipt (Image/PDF)
- OCR Text Extraction
- Expense Dashboard
- Warranty Tracker
- Reminder Notifications
- Offline Support (PWA)
- Unified light theme
- Desktop dashboard sidebar with responsive mobile drawer
- Shared header with account settings access
- Search & Filter
- Monthly Analytics
- Multi-currency expenses with separate currency totals

### Account deletion
Logout and Delete Account are available in Settings and the Dashboard sidebar. Deletion runs with the signed-in Firebase user, so Firestore, Storage, and Realtime Database rules must allow users to delete their own records. No separate admin backend is required.
